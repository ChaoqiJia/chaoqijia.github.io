Chaoqi Jia 学术主页 — GitHub 手动上传版

1. 解压本 ZIP。GitHub 不会自动将 ZIP 解压为网站，请上传解压后的文件。
2. 创建公开仓库：<你的GitHub用户名全小写>.github.io。
3. 使用 Add file → Upload files，上传本目录中的 index.html、assets 文件夹、.nojekyll，以及许可证文件。
   index.html 必须位于仓库根目录；不要把外面的 chaoqi-jia-github-manual 文件夹一起套进去。
   在 Mac Finder 中按 Command + Shift + . 可显示 .nojekyll；也可在 GitHub 用 Add file → Create new file 新建该文件。
4. 将改动提交到 main 分支。
5. Settings → Pages → Build and deployment → Source 选择 Deploy from a branch。
6. Branch 选择 main，目录选择 /(root)，点击 Save。
7. 部署完成后，从 Settings → Pages → Visit site 打开网址。

这是已经构建好的静态网页，不需要 Node.js、Jekyll、终端或自定义 Actions 工作流。
若仓库里此前已启用 Deploy academic homepage 自定义工作流，请先停用该工作流，避免两套部署方式同时更新网站。
发布后的 GitHub Pages 网站会公开访问。原有的私有 Sites 网站不会因此改变。

这份手动上传版移除了旧私有网址专属的 canonical、og:image 和 JSON-LD url 元数据。
网页及照片使用相对路径，可部署到个人主页根地址或普通仓库路径。
确定最终公开网址后，可补上对应 canonical、og:image 和 JSON-LD url，完善搜索及分享元数据。

日后手动维护：编辑 index.html 或替换 assets 中的文件，再重新上传。
本机原始项目仍在 chaoqi-jia/：长期维护可以修改 index.template.html / publications.json，构建后重新导出静态网页。
